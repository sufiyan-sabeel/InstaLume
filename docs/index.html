Features

Liquid Glass UI

iOS-inspired translucent system with iOS / Universal modes, opacity, blur, and corner controls. Graceful fallback where blur is unsafe.

Distraction controls

Feed, Reels, Explore, ads, and suggested surfaces with per-surface toggles, nav visibility, swipe guard, and landing page.

Privacy

No passwords, tokens, or telemetry. Ghost Mode entries are honestly marked version-dependent when no safe fingerprint exists.

Backup & restore

JSON schema v1 export / import / merge without overwrite. Validated, credential-free, unknown keys preserved.

Version compatibility

Tested IG base 446.0.0.49.77. Patch registry + diagnostics fail closed on untested versions.

Modular features

Feature registry with id, category, versions, dependencies, and honest status for maintainable IG updates.

Screenshots

Screenshots show structure, not proprietary Instagram UI. No Instagram branding is copied into InstaLume assets.
